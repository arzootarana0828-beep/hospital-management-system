# Hospital Management System

## Project Description

A web-based Hospital Management System developed using Python Flask, MySQL, HTML, and CSS.

## Features

- Admin Login
- Dashboard
- Patient Management
- Doctor Management
- Appointment Management
- Search functionality
- Add, Edit and Delete records
- MySQL database
- SQL JOIN operations

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- Jinja2

## How to Run

Activate the virtual environment:

.\venv\Scripts\Activate.ps1

Install dependencies:

pip install -r requirements.txt

Run the application:

python app.py

Open in browser:

http://127.0.0.1:5000/

## Database

Database name:

hospital_db

Main tables:

- users
- patients
- doctors
- appointments
